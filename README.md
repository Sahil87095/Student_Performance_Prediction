📊 Student Score Prediction – ML Project

This project predicts a student's Math Score using demographic details, parental education, lunch type, test preparation status, and Reading/Writing scores.
It includes a fully functional Streamlit web app powered by a trained Linear Regression pipeline.

Model Inputs:

gender

race/ethnicity

parental_level_of_education

lunch

test_preparation_course

reading_score

writing_score

Tech Used:

• Python 
• Streamlit 
• Scikit-Learn 
• Pandas 
• NumPy 
• Matplotlib 
• Seaborn

Features:

ML workflow (preprocessing → training → evaluation → deployment)

Linear Regression model saved as a Scikit-Learn Pipeline

Real-time predictions through a Streamlit UI

Clean input form for categorical and numerical features
